# GeoPress 🗺️📰

GeoPress is a **location-based news web application** that visualizes local news and incidents directly on a map. It helps users quickly understand **what happened, where it happened, and what is happening nearby**, all in one place.

---

## ❓ Problem It Solves

Traditional news platforms present information in text-heavy formats without clear geographical context. This creates several problems:

* Users cannot easily identify **incident locations**
* Local and hyperlocal news gets buried under national/global news
* Emergency or safety-related incidents are hard to track in real time
* Citizens struggle to understand what is happening **around them**

**GeoPress solves this by combining news with maps**, allowing users to visually explore incidents based on location.

---

## 🚀 Features

* 🗞️ **Geo-Tagged News** – Each news article is linked with latitude and longitude
* 🗺️ **Interactive Map View** – Incidents displayed as markers on a map
* 📍 **Click Marker to Read News** – View full news details by selecting a location
* 🔍 **Category-Based Filtering** – Crime, accidents, events, alerts, etc.
* 🔐 **Authentication & Authorization** – Secure login system
* 📱 **Responsive UI** – Optimized for mobile and desktop devices

---

## 🛠️ Tech Stack (MERN Stack)

### Frontend

* **React.js** – Component-based UI development
* **Tailwind CSS** – Responsive and modern styling
* **Mapbox GL / Google Maps API** – Map rendering and geolocation
* **Axios** – API communication

### Backend

* **Node.js** – Server-side runtime
* **Express.js** – REST API development

### Database

* **MongoDB** – Stores news, users, and location data
* **Mongoose** – MongoDB object modeling

### Authentication & Security

* **JWT (JSON Web Tokens)** – User authentication
* **bcrypt.js** – Password encryption
